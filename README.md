# alroba.github.io

Personal site of Álvaro Bachiller, Support Lead at CARTO. Live at https://alroba.github.io

Static HTML, CSS and JavaScript, no build step.

- `index.html`: content (English by default; Spanish strings live in `js/main.js`)
- `css/styles.css`: design tokens at the top, light and dark mode
- `js/main.js`: language switch (remembers the choice, detects the browser language), email link and copy button
- `cv/`: downloadable CVs
- `img/`: favicon and social preview image (`og.png`)
